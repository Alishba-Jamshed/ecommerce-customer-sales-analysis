# E-commerce Customer & Sales Performance Analysis

## Project Overview

This project analyses e-commerce transaction data to understand sales performance, customer purchasing behaviour, product performance, and customer retention.

The objective is to identify meaningful business insights and opportunities to improve revenue and customer retention using data analysis and visualisation.

## Project Objectives

- Analyse overall sales and revenue performance.
- Understand customer purchasing patterns and repeat behaviour.
- Identify top-performing products.
- Examine sales performance across different countries.
- Analyse monthly revenue trends.
- Present key findings through an interactive Power BI dashboard.

## Dataset

**Dataset:** Online Retail II (2009–2011)

The dataset contains historical online retail transactions, including invoice details, product descriptions, quantities, prices, customer IDs, and country information.

The cleaned dataset contains:

- **Rows:** 1,007,914
- **Columns:** 9

The full cleaned dataset is not included in this repository because of its large file size.

## Tools & Technologies

- **Python:** Data cleaning, analysis, and visualisation.
- **Power BI:** Interactive dashboard development.
- **SQL:** Analytical concepts and data-related learning.

## Key Areas of Analysis

1. **Sales Performance:** Monthly revenue trends and overall business performance.
2. **Customer Analysis:** Customer purchasing behaviour and repeat customer contribution.
3. **Product Performance:** Best-performing products based on revenue and quantity sold.
4. **Geographic Analysis:** Revenue contribution across different countries.
5. **Customer Segmentation:** RFM-based customer segmentation and retention analysis.
